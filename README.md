# 🌱 GreenLoop — Turning Township Waste into Community Value
> **Recycle. Earn. Grow.**

Academic Prototype developed for **University Hackathon 2026**  
**Theme:** Sustainable Living & Community Empowerment (People & Planet)

---

## 📌 Project Overview
GreenLoop bridges the gap between individual recycling efforts and shared township improvements through a dual-reward model:
1. **Find Hubs:** Locate designated neighborhood recycling drop-off points.
2. **Staff Verification Desk:** Hub operators weigh materials and credit instant GreenPoints.
3. **Resident Web Pass & Rewards:** Residents track balances, redeem merchant vouchers, and review drop-off history.
4. **Resident-Voted Greening:** Households vote on community pocket gardens and shade-tree projects.
5. **Impact Dashboard:** Real-time metrics tracking total waste diverted, points issued, and community votes.
