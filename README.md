# 🌱 GreenLoop — Turning Township Waste into Community Value
> **Recycle. Earn. Grow.**

Academic Prototype developed for **University Hackathon 2026**  
**Theme:** Sustainable Living & Community Empowerment (Planet)

---

## 📌 Project Overview
GreenLoop addresses the township recycling inertia by bridging the gap between individual household waste separation and tangible neighborhood greening:
* **The Problem:** Inconvenient drop-offs and invisible impact discourage household recycling.
* **The Solution:** A dual-reward model where verified household recycling earns personal **GreenPoints** while democratically prioritizing and funding **community pocket gardens**.

---

## 🚀 Core Features
1. **Find Nearby Centres:** Proximity-sorted directory with material filtering and distance estimates. Clearly distinguishes independent real-world facilities (e.g., IPC Shopping Centre) from proposed demonstration hubs.
2. **My QR Pass:** Generates a unique resident QR pass for quick manual ID verification at drop-off hubs.
3. **Staff Verification Desk:** Frontline staff interface with input validation, material compatibility checks, and instant point crediting.
4. **GreenPoints & Rewards:** Dual-balance tracking (available spendable balance vs. cumulative historical points) with demo voucher redemptions.
5. **Community Project Voting:** One vote per household per cycle to prioritize neighborhood greening projects.
6. **Township Impact Dashboard:** Aggregated metrics tracking verified material weights, total points awarded, participating households, and community votes.
